AWS Service Matching Cheat-Sheet

Based on the in-scope services list in the AIF-C01 exam guide v1.4. This is a study aid only. Check the AWS docs if something looks wrong.

Exam tip: most service questions ask "which service does X?". Look for the keyword in the Use case column.

AI/ML services

Service What it does Typical use case Not to be confused with
Amazon Bedrock Use foundation models (Anthropic, Meta, Amazon Titan/Nova, etc.) through a managed API. Also includes Knowledge Bases, Agents, Guardrails, model evaluation Build GenAI apps without running servers SageMaker (you build, train, and host your own models)
Bedrock Knowledge Bases Managed RAG: it loads your docs, makes embeddings, stores them in a vector DB, and retrieves them Chatbot that answers from company docs Fine-tuning (changes model weights; RAG does not)
Agents for Bedrock (now "Bedrock Agents Classic", in maintenance since July 30, 2026; AWS recommends Bedrock AgentCore for new agents. The exam may still use the older name) Lets an FM plan and carry out tasks with many steps by calling APIs or tools "Book a trip", "process an order" Plain prompting (one step)
Guardrails for Bedrock Content filters, denied topics, word filters, PII redaction, and grounding checks Block harmful or off-topic answers IAM (access control, not content control)
PartyRock No-code playground for building GenAI apps. It runs on Bedrock Learning and prototyping Bedrock itself (production API)
Amazon Q (Business / Developer) (Q Developer: new IDE sign-ups ended May 15, 2026 in favor of Kiro; in the console it is now called the AWS assistant) GenAI assistant. Business: answers from company data. Developer: coding help in the IDE or console Employee assistant; writing and explaining code Bedrock (a platform for building; Q is a ready-made assistant)
Amazon SageMaker A full ML platform to build, train, tune, deploy, and monitor your own models Every stage of a custom ML model Bedrock (uses ready-made FMs)
SageMaker JumpStart A hub of pre-trained models and ready-made solution templates Get started fast with open-source or pre-trained models Bedrock (JumpStart deploys models onto your own endpoints)
SageMaker Data Wrangler Prepare data and build features with a low-code screen Clean and reshape data Glue (general ETL)
SageMaker Feature Store One place to keep ML features so you can reuse them Share features between training and inference Data Wrangler (creates features, does not store them)
SageMaker Model Monitor Spots drift in data or model quality in production Send an alert when the model gets worse CloudWatch (infrastructure metrics)
SageMaker Clarify Finds bias and explains predictions (explainability) Bias report; feature importance Model Monitor (drift)
SageMaker Model Cards Write down a model's purpose, data, risks, and performance Records for governance and transparency Clarify (it analyzes; it does not document)
SageMaker Ground Truth Data labeling with human workers Build labeled datasets A2I (people review predictions; it does not label data)
Amazon Augmented AI (A2I) A workflow where people review predictions the model is unsure about Checks with a human in the loop Ground Truth
Amazon Comprehend NLP: finds sentiment, entities, key phrases, language, PII, and topics Analyze customer reviews Lex (conversation), Kendra (search)
Amazon Kendra (maintenance mode; closed to new customers from July 30, 2026, Bedrock Knowledge Bases is the suggested alternative) Smart company search (ask questions in plain language and get answers from documents) Search company knowledge bases OpenSearch (general search/vector store)
Amazon Lex Build chatbots that talk with people (voice or text) Customer-service chatbot, IVR Comprehend (it analyzes text; it does not hold a conversation)
Amazon Polly Text to speech Read articles aloud Transcribe (the reverse)
Amazon Transcribe Speech to text Call transcripts, subtitles Polly
Amazon Translate Language translation Localize content Comprehend (language detection only)
Amazon Rekognition Analyzes images and video: objects, faces, unsafe content, text in images Detect unsafe content; face match Textract (document text/forms)
Amazon Textract Pulls text, tables, and forms out of scanned documents Invoices, ID forms Rekognition
Amazon Personalize Recommendations tailored to each person, in real time "Customers also bought" Forecasting or ranking built by hand
Amazon Fraud Detector (closed to new customers since Nov 7, 2025; still named in the exam guide's use cases) Uses ML to find online fraud Fake accounts, payment fraud Macie (finds sensitive data)

Data, storage, and vector databases

Service Role for AI
Amazon S3 Main place to keep training data, documents for RAG, and model files
S3 Glacier Low-cost storage for old data you rarely need
Amazon OpenSearch Service Vector store for embeddings; also search and analytics
Aurora / RDS for PostgreSQL Vector store via the pgvector extension
Amazon Neptune Graph DB and vector store (GraphRAG). Knowledge Bases uses Neptune Analytics
Amazon DocumentDB Works like MongoDB; supports vector search
DynamoDB / ElastiCache / MemoryDB NoSQL, caching, and in-memory DB (helper roles)
AWS Glue / Glue DataBrew ETL / visual data prep
Amazon EMR Processes very large data (Spark)
Lake Formation Build data lakes and control access to them
Amazon Redshift Data warehouse
QuickSight BI dashboards
AWS Data Exchange Find and sign up for datasets from other companies

Vector DB memory trick: OpenSearch, Aurora/RDS-Postgres, Neptune, DocumentDB (and Bedrock Knowledge Bases can manage these for you).

Other in-scope infrastructure

EC2 (compute, incl. GPU/Trainium/Inferentia instances), ECS and EKS (containers), CloudFront (CDN), VPC (networking).

Quick decision flow

Need text from...
  image/scanned doc -> Textract (forms/tables) | Rekognition (objects, faces, text in photos)
  audio             -> Transcribe
Need to produce...
  speech            -> Polly
  translation       -> Translate
  chatbot           -> Lex (custom flow) | Q (assistant) | Bedrock (custom GenAI)
Analyze text        -> Comprehend
Search documents    -> Kendra
Recommendations     -> Personalize
Custom ML model     -> SageMaker
Use an FM via API   -> Bedrock
