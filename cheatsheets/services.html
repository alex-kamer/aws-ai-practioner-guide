AWS Service Matching Cheat-Sheet

Based on the in-scope services list in the AIF-C01 exam guide v1.4. Study aid only: verify against AWS docs if something seems off.

Exam tip: most service questions are "which service does X?". Find the keyword in the Use case column.

AI/ML services

Service What it does Typical use case Not to be confused with
Amazon Bedrock Managed API access to foundation models (Anthropic, Meta, Amazon Titan/Nova, etc.); includes Knowledge Bases, Agents, Guardrails, model evaluation Build GenAI apps without managing infrastructure SageMaker (you build/train/host your own models)
Bedrock Knowledge Bases Managed RAG: ingest docs, create embeddings, store in a vector DB, retrieve Chatbot grounded in company docs Fine-tuning (changes model weights; RAG does not)
Agents for Bedrock Lets an FM plan and execute multi-step tasks by calling APIs/tools "Book a trip", "process an order" Plain prompting (single step)
Guardrails for Bedrock Content filters, denied topics, word filters, PII redaction, grounding checks Block harmful or off-topic output IAM (access control, not content control)
PartyRock No-code playground for building GenAI apps, backed by Bedrock Learning and prototyping Bedrock itself (production API)
Amazon Q (Business / Developer) GenAI assistant. Business: answers from company data. Developer: coding help, in IDE/console Employee assistant; code generation, explanation Bedrock (a platform for building; Q is a ready-made assistant)
Amazon SageMaker Full ML platform: build, train, tune, deploy, monitor custom models Custom ML model lifecycle Bedrock (consumes ready-made FMs)
SageMaker JumpStart Hub of pre-trained models and solution templates Quick-start with open-source/pre-trained models Bedrock (JumpStart deploys models onto your own endpoints)
SageMaker Data Wrangler Data prep/feature engineering with low-code UI Clean and transform data Glue (general ETL)
SageMaker Feature Store Central store of ML features for reuse Share features between training and inference Data Wrangler (creates features, doesn't store them)
SageMaker Model Monitor Detects data/model quality drift in production Alert when model degrades CloudWatch (infrastructure metrics)
SageMaker Clarify Detects bias; explains predictions (explainability) Bias report; feature importance Model Monitor (drift)
SageMaker Model Cards Document model purpose, data, risks, performance Governance and transparency documentation Clarify (analysis, not documentation)
SageMaker Ground Truth Data labeling with human workers Build labeled datasets A2I (human review of predictions, not labeling)
Amazon Augmented AI (A2I) Human review workflow for low-confidence predictions Human-in-the-loop checks Ground Truth
Amazon Comprehend NLP: sentiment, entities, key phrases, language, PII detection, topic modeling Analyze customer reviews Lex (conversation), Kendra (search)
Amazon Kendra Intelligent enterprise search (natural language Q&A over documents) Search company knowledge bases OpenSearch (general search/vector store)
Amazon Lex Build conversational chatbots (voice/text) Customer-service chatbot, IVR Comprehend (analysis, not dialogue)
Amazon Polly Text to speech Read articles aloud Transcribe (the reverse)
Amazon Transcribe Speech to text Call transcripts, subtitles Polly
Amazon Translate Language translation Localize content Comprehend (language detection only)
Amazon Rekognition Image/video analysis: objects, faces, moderation, text in images Detect unsafe content; face match Textract (document text/forms)
Amazon Textract Extract text, tables, forms from scanned documents Invoices, ID forms Rekognition
Amazon Personalize Real-time personalized recommendations "Customers also bought" Forecasting/ranking built by hand
Amazon Fraud Detector Detect online fraud using ML Fake accounts, payment fraud Macie (sensitive data discovery)

EC2 (compute, incl. GPU/Trainium/Inferentia instances), ECS and EKS (containers), CloudFront (CDN), VPC (networking).

Quick decision flow

Need text from...
  image/scanned doc -> Textract (forms/tables) | Rekognition (objects, faces, text in photos)
  audio             -> Transcribe
Need to produce...
  speech            -> Polly
  translation       -> Translate
  chatbot           -> Lex (custom flow) | Q (assistant) | Bedrock (custom GenAI)
Analyze text        -> Comprehend
Search documents    -> Kendra
Recommendations     -> Personalize
Custom ML model     -> SageMaker
Use an FM via API   -> Bedrock
