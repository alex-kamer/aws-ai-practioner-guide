Glossary

Study aid for AIF-C01. Terms are grouped by topic. The domain number shows where the exam tests it.

Core AI/ML (Domain 1)

  • AI: Computer systems that do tasks that normally need human thinking. This is the broadest term.
  • ML: A part of AI where models learn patterns from data. Nobody writes the rules by hand.
  • Deep learning: A part of ML that uses neural networks with many layers. It needs lots of data and computing power.
  • Neural network: Layers of connected nodes ("neurons"). The network learns the weights (numbers that set how strongly nodes connect) from data.
  • Model / algorithm: The algorithm is the learning method. The model is the trained result that makes predictions.
  • Training vs inference: Training builds the model from data. Inference uses the model to predict on new data. Inference can be batch (many at once, no rush) or real-time (fast answers, one request at a time).
  • Supervised learning: Learns from labeled data (classification, regression).
  • Unsupervised learning: Finds structure in unlabeled data (clustering).
  • Reinforcement learning: An agent learns by trial and error and gets rewards for good moves. RLHF adds feedback from humans.
  • Classification / regression / clustering: Pick a category / predict a number / group similar items.
  • Labeled vs unlabeled data: Labeled data has the right answer attached. Data can be structured (tables) or unstructured (text, images). It can also be time-series (values over time).
  • Computer vision / NLP: AI on images and video / on human language.
  • Feature / feature engineering: An input value / creating and reshaping inputs to help the model.
  • Hyperparameter: A setting you pick before training (like learning rate or number of layers). The model does not learn it from data.
  • Overfitting: The model memorizes the training data and does poorly on new data (low bias, high variance).
  • Underfitting: The model is too simple to catch the patterns (high bias, low variance).
  • Bias (statistical) vs variance: Bias is error from being too simple. Variance is how much the model reacts to noise in the training data. This is not the same as societal bias.
  • Precision / recall: Precision = of the items the model called positive, how many were right. Recall = of the real positives, how many the model found.
  • Accuracy: The share of all predictions that were correct. It can mislead when one class is much bigger than the others.
  • F1 score: A single score that balances precision and recall.
  • AUC (ROC): How well a classifier tells the classes apart, at every cutoff. 1.0 is perfect, 0.5 is random.
  • Confusion matrix: A table that counts true and false positives and negatives.
  • MLOps: Using DevOps habits for ML: repeatable pipelines, monitoring, and retraining.
  • ML pipeline: Data collection, EDA, pre-processing, feature engineering, training, tuning, evaluation, deployment, monitoring.
  • EDA: Exploratory data analysis. You look at the data to understand it before you build a model.
  • Model drift / data drift: The model gets worse over time because real-world data changes.

Generative AI (Domains 2 and 3)

  • Generative AI: Models that make new content (text, images, audio, code).
  • Foundation model (FM): A large model pre-trained on a wide range of data. It can be adapted to many tasks.
  • LLM: A foundation model for language. It is built on the transformer design.
  • Transformer: A model design that uses "attention" to see how tokens relate to each other. Most LLMs are built on it.
  • Token: A small piece of text (part of a word) that the model reads and writes. Pricing and limits are counted in tokens.
  • Context window: The most tokens (input plus output) a model can handle at once.
  • Embedding: A list of numbers (a vector) that stands for the meaning of text or images. Similar meaning = nearby vectors.
  • Vector database: Stores embeddings so you can search by similarity.
  • Chunking: Splitting documents into smaller pieces before you embed them.
  • RAG (Retrieval-Augmented Generation): Find relevant documents when a question comes in and add them to the prompt. This cuts down on hallucination. It also lets the model use fresh data without retraining.
  • Multi-modal model: Works with more than one type of data (text and images).
  • Diffusion model: Makes images by removing noise a little at a time. Image-generation models use it.
  • Prompt / prompt engineering: The input you give the model / writing inputs to get better outputs.
  • Zero-shot / one-shot (single-shot) / few-shot: No examples / one example / a few examples in the prompt.
  • Chain-of-thought: Asking the model to think through the problem step by step.
  • Negative prompt: Tells the model what to avoid.
  • Prompt template: A prompt you can reuse, with blanks to fill in.
  • Temperature: How random the output is. Low = focused and predictable. High = creative and varied.
  • Top-p / top-k: Limit the pool of tokens the model can pick next. Lower values = more predictable.
  • Max tokens / stop sequences: Cap the output length / say where to stop.
  • Hallucination: Output that sounds sure but is false or made up.
  • Nondeterminism: The same prompt can give different answers each time.
  • Pre-training: The first round of training on a huge amount of data to build an FM.
  • Continuous pre-training: More pre-training on unlabeled data from one field.
  • Fine-tuning: More training on labeled data for a task or field. It changes the model weights.
  • Instruction tuning: Fine-tuning with (instruction, response) pairs, so the model learns to follow directions.
  • Transfer learning: Using a model trained on one task as the starting point for another task.
  • In-context learning: Teaching the model with examples in the prompt. The weights do not change.
  • RLHF: Reinforcement learning from human feedback. It steers outputs toward what people prefer.
  • Agent: An FM that plans and calls tools or APIs to finish tasks with many steps.
  • Provisioned throughput: Bedrock model capacity you reserve with a commitment. It was traditionally needed for custom models (on-demand deployment now exists for some). Compare with on-demand, where you pay per token.
  • ROUGE: A score for summaries. It measures overlap with a reference text and focuses on recall.
  • BLEU: A score for translation. It measures n-gram (short word run) overlap and focuses on precision.
  • BERTScore: A score for similarity in meaning. It uses embeddings.
  • Benchmark dataset: A standard dataset used to compare models.

Responsible AI (Domain 4)

  • Fairness: The model treats all groups fairly.
  • Bias (societal): Unfair results that repeat in a pattern. They often come from data that does not represent everyone.
  • Explainability / interpretability: Being able to understand why a model made a prediction.
  • Transparency: Being open about how the model works, how it was trained, and what its limits are.
  • Robustness: The model keeps working well when input is unexpected or meant to trick it.
  • Veracity: How truthful the outputs are.
  • Subgroup analysis: Checking how well the model performs for each demographic group on its own.
  • Human-centered design: Building AI around what people need, with human oversight and clear behavior.

Security and governance (Domain 5)

  • Prompt injection: Harmful input that overrides the model's instructions.
  • Jailbreaking: Prompts written to get around safety rules.
  • Prompt poisoning / hijacking / exposure: Tampered data or instructions / taking over the model's behavior / leaking what is in the prompt.
  • Shared responsibility model: AWS secures the cloud itself (the infrastructure). You secure what you put in the cloud (data, IAM, configuration).
  • Least privilege: Give only the permissions that are needed.
  • Data lineage: A record of where data came from and how it changed.
  • Data residency: A rule that data must stay in a certain region or country.
  • Generative AI Security Scoping Matrix: An AWS framework that sorts GenAI use (from using a public app to training your own model). It helps you see which security tasks are yours.
  • PII: Personally identifiable information.
