Glossary

Study aid for AIF-C01. Terms are grouped by topic. The domain number shows where the exam tests it.

Core AI/ML (Domain 1)

  • AI: Systems that perform tasks normally requiring human intelligence. The broadest term.
  • ML: A subset of AI where models learn patterns from data instead of being explicitly programmed.
  • Deep learning: A subset of ML using multi-layer neural networks. Needs lots of data and compute.
  • Neural network: Layers of connected nodes ("neurons") that learn weights from data.
  • Model / algorithm: The algorithm is the learning procedure; the model is the trained result used for predictions.
  • Training vs inference: Training builds the model from data; inference uses it to predict on new data. Inference can be batch (many at once, not time-critical) or real-time (low latency, one request at a time).
  • Supervised learning: Learns from labeled data (classification, regression).
  • Unsupervised learning: Finds structure in unlabeled data (clustering).
  • Reinforcement learning: An agent learns by trial and reward (and RLHF uses human feedback).
  • Classification / regression / clustering: Predict a category / predict a number / group similar items.
  • Labeled vs unlabeled data: Labeled has the right answer attached. Data can be structured (tables) or unstructured (text, images), and may be time-series.
  • Computer vision / NLP: AI on images and video / on human language.
  • Feature / feature engineering: An input variable / creating and transforming inputs to help the model.
  • Hyperparameter: A setting you choose before training (learning rate, number of layers), not learned from data.
  • Overfitting: Model memorizes training data and does poorly on new data (low bias, high variance).
  • Underfitting: Model is too simple to capture the patterns (high bias, low variance).
  • Bias (statistical) vs variance: Bias is error from oversimplifying; variance is sensitivity to training data noise. Not the same as societal bias.
  • Precision / recall: Precision = of the items predicted positive, how many were right. Recall = of the real positives, how many were found.
  • Accuracy: Share of all predictions that were correct. Misleading with imbalanced classes.
  • F1 score: Balance of precision and recall.
  • AUC (ROC): How well a classifier separates classes across thresholds. 1.0 is perfect, 0.5 is random.
  • Confusion matrix: Table of true/false positives and negatives.
  • MLOps: Applying DevOps practices to ML: repeatable pipelines, monitoring, and retraining.
  • ML pipeline: Data collection, EDA, pre-processing, feature engineering, training, tuning, evaluation, deployment, monitoring.
  • EDA: Exploratory data analysis, understanding the data before modeling.
  • Model drift / data drift: Model performance degrades as real-world data changes over time.

Generative AI (Domains 2 and 3)

  • Generative AI: Models that create new content (text, images, audio, code).
  • Foundation model (FM): Large model pre-trained on broad data, adaptable to many tasks.
  • LLM: A foundation model for language, built on the transformer architecture.
  • Transformer: Architecture using attention to model relationships among tokens. Basis of most LLMs.
  • Token: A chunk of text (word piece) the model reads and generates. Pricing and limits are token-based.
  • Context window: Maximum number of tokens (input plus output) a model can handle at once.
  • Embedding: A numeric vector representing the meaning of text/images. Similar meaning = nearby vectors.
  • Vector database: Stores embeddings for similarity search.
  • Chunking: Splitting documents into pieces before embedding them.
  • RAG (Retrieval-Augmented Generation): Retrieve relevant documents at query time and add them to the prompt. Reduces hallucination and uses fresh data without retraining.
  • Multi-modal model: Handles more than one data type (text and images).
  • Diffusion model: Generates images by gradually removing noise. Used by image-generation models.
  • Prompt / prompt engineering: The input to the model / crafting inputs to get better outputs.
  • Zero-shot / one-shot (single-shot) / few-shot: No examples / one example / several examples in the prompt.
  • Chain-of-thought: Prompting the model to reason step by step.
  • Negative prompt: Tells the model what to avoid.
  • Prompt template: Reusable prompt with placeholders.
  • Temperature: Randomness of output. Low = focused and deterministic; high = creative and varied.
  • Top-p / top-k: Limit the pool of candidate next tokens. Lower values = more predictable.
  • Max tokens / stop sequences: Limit output length / where to stop.
  • Hallucination: Confident but false or made-up output.
  • Nondeterminism: The same prompt can give different outputs.
  • Pre-training: Initial training on massive data to build an FM.
  • Continuous pre-training: Further pre-training on unlabeled domain data.
  • Fine-tuning: Further training on labeled data for a task or domain. Changes model weights.
  • Instruction tuning: Fine-tuning with (instruction, response) pairs so the model follows directions.
  • Transfer learning: Reusing a model trained on one task as the starting point for another.
  • In-context learning: Teaching the model through examples in the prompt, with no weight changes.
  • RLHF: Reinforcement learning from human feedback; aligns outputs with human preferences.
  • Agent: FM that plans and calls tools/APIs to complete multi-step tasks.
  • Provisioned throughput: Reserved Bedrock model capacity (commitment), needed for custom models. Versus on-demand, pay-per-token.
  • ROUGE: Evaluation metric for summarization (overlap with reference, recall-oriented).
  • BLEU: Evaluation metric for translation (precision-oriented n-gram overlap).
  • BERTScore: Semantic-similarity metric using embeddings.
  • Benchmark dataset: Standard dataset for comparing models.

Responsible AI (Domain 4)

  • Fairness: Model treats groups equitably.
  • Bias (societal): Systematic unfair outcomes, often from unrepresentative data.
  • Explainability / interpretability: Ability to understand why a model made a prediction.
  • Transparency: Openness about how the model works, was trained, and its limits.
  • Robustness: Reliable performance under unexpected or adversarial input.
  • Veracity: Truthfulness of outputs.
  • Subgroup analysis: Evaluating performance separately per demographic group.
  • Human-centered design: Designing AI around human needs, oversight, and clarity.

Security and governance (Domain 5)

  • Prompt injection: Malicious input that overrides the model's instructions.
  • Jailbreaking: Prompts crafted to bypass safety restrictions.
  • Prompt poisoning / hijacking / exposure: Tampered data/instructions, taking over the model's behavior, leaking prompt contents.
  • Shared responsibility model: AWS secures the cloud (infrastructure); you secure what is in the cloud (data, IAM, configuration).
  • Least privilege: Grant only the permissions needed.
  • Data lineage: Record of where data came from and how it changed.
  • Data residency: Requirement that data stays in a specific region or country.
  • Generative AI Security Scoping Matrix: AWS framework that classifies GenAI use (from using a public app to training your own model) to scope security responsibilities.
  • PII: Personally identifiable information.
