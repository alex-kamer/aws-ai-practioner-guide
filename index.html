AIF-C01 Study Guide

Notes, cheat-sheets, quizzes, and a gap map for the AIF-C01 exam. Content follows the official exam guide v1.4. It is a study aid, so verify against AWS docs if something looks off.

Exam facts: 65 questions (50 scored, 15 unscored) · passing score 700 / 1000 · no penalty for guessing · compensatory scoring, so you don't need to pass each domain on its own.

The study loop

cheat-sheets -> practice exam -> gap map -> targeted notes + quizzes -> labs -> mock exam -> repeat

Schedule

Days are relative to the practice exam (Day 0). Shift them if dates move, and compress or stretch Phase 2 to fit the real exam date.

Phase 1: before the practice exam (about 2 days)

Day -2Skim the services cheat-sheet. Don't start labs yet.
Day -1Skim the glossary, then re-skim services. Under an hour a day is enough, because the practice exam is your diagnostic.

Phase 2: after the practice exam (about 12 days)

Day 0Fill in the gap map: scores per domain and the topics you missed. After each run of the in-site practice exam, "Save to gap map" does this for you.
Days 1-3Study the top-ranked domain's notes, then do its quiz.
Days 4-6Next two ranked domains.
Days 7-8Labs, starting with Domain 3 (prompting, knowledge base, guardrails).
Day 9Second practice exam or timed mock. Add it as a new attempt in the gap map.
Days 10-11Re-study anything still weak.
Day 12Second timed mock if time allows, then light cheat-sheet review only.
Day 13Rest. Brief glossary review, check exam logistics.
Day 14Real exam.

Domains 2 and 3 make up 52% of the exam, so lean on them if you're torn.
